# Results not homework

EXIT check for every non-trivial ask. Do not wait for the human to type
`/results-not-homework`. End on a mergeable artifact, not a lecture.
This skill is the named contract for that default. Same shape as
`one-shot-task`: agents start here automatically when a task is about
to close. It does not replace that default.

## Route

1. Before you stop, name the artifact you leave:
   - open PR with Summary / Done means / Keep, or
   - written brief / decision note, or
   - scorecard or measured claim with evidence, or
   - `VERIFIED` / `NOT VERIFIED` / `INCONCLUSIVE` from `verify-this`.
2. If the ask needed a change and you did not open a PR (or land the
   named artifact), you are not done. Finish the artifact or say what
   blocked it with evidence.
3. Never close with a "you should…" / "next steps for you" homework
   list. If follow-up is real, either do it now or file it as a
   checkable item with an owner and Done means. Do not hand the human
   a chore list as the deliverable.

## Fail closed

A status dump, a plan with no artifact, or a bullet wall of advice is
not an exit. Re-open the work or report the blocker. Builds and
self-reports are not evidence.

## Autopilot stays off

Leave Autopilot and TRUST-NEXT off unless Dark has already greened them
with evidence. Do not invent Autopilot. Do not self-merge.

## Language

Plain workstream nouns only. No bot persona names, no role titles, no
phase / slice / section / wave labels, no em dashes. Orwell on the
prose: say what changed and why.

## Reply shape

Name the artifact (PR URL, brief path, verdict). One line on what is
still open, if anything. No homework list.
